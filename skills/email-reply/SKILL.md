# 곤란한 업무 메일 답장

받은 메일과 **내가 정한 결론**을 받아 답장 초안을 씁니다. 결론은 스킬이 정하지 않습니다. 정해진 결론을 상대가 기분 상하지 않게 전하는 문장만 씁니다.

> 이 스킬은 stanlee7의 `korean-office-skills` 중 `email-reply-kr`(MIT 라이선스)를 바탕으로 고쳐 만들었습니다. 라이선스 전문은 같은 폴더의 `LICENSE-stanlee7.txt`에 있습니다.

## 내가 고칠 수 있는 설정
- 기본 상대: 고객 (예: 협력사, 사내 윗사람, 동료)
- 말투: 격식 있는 존댓말
- 본문 길이: 3~6문장
- 꼭 넣을 말: (여기에 적어 주세요)
- 쓰지 않을 말: (여기에 적어 주세요)

## 하는 일
1. 입력을 확인합니다. 아래 두 가지가 있는지 봅니다.
   - **결론**: 거절하는지, 미루는지, 일부만 받는지, 사과하는지
   - **상대와의 관계**: 고객, 협력사, 사내 윗사람, 동료 중 무엇인지 (없으면 위 설정의 기본 상대로 보고 가장 정중하게 씁니다)
2. 입력이 비어 있으면 초안을 쓰지 않고 한 번만 안내합니다. 예: 「받은 메일 내용과, 어떻게 답하고 싶은지(거절·일정 변경·일부만 수락·사과)를 함께 붙여 넣어 주세요.」
3. 결론이 없으면 초안을 쓰지 말고 **한 번만** 묻습니다. 예: 「이번 요청은 거절할까요, 일정을 미룰까요, 일부만 받을까요?」 「알아서 해 주세요」라고 하면 가장 보수적인 안(확답 없이 내부 확인 후 회신)으로 쓰고, 그렇게 썼다고 알립니다.
4. 아래 규칙과 뼈대에 맞춰 초안을 씁니다.
5. 초안을 대화창에 보여 주고 고칠 곳이 있는지 묻습니다. 메일을 대신 보내지 않습니다.

## 지키는 것 (AI가 약속을 덧붙이지 않기)
1. **내가 말하지 않은 약속을 쓰지 않습니다.** 새 날짜, 할인, 보상, 무상 제공, 「다음에는 꼭」, 「최우선으로 처리」, 「재발 방지 대책 마련」 같은 약속은 내가 말한 경우에만 씁니다.
2. **날짜와 숫자는 내가 준 그대로.** 미룬 일정, 금액, 수량을 새로 만들지 않습니다. 필요한데 없으면 `[확인 필요: 날짜]`, `[확인 필요: 금액]`처럼 빈칸으로 둡니다. 받는 사람 이름을 모르면 「고객님」처럼 호칭으로 쓰고, 「확인할 것」에 이름을 알려 달라고 적습니다.
3. **책임 인정은 내가 말한 범위까지만.** 사과 메일에서도 내가 인정한 범위를 넘어 「전적으로 저희 잘못」처럼 넓히지 않습니다. 상대의 상황이나 감정(「걱정이 크셨을 것」 등)도 내가 말하지 않았으면 짐작해서 쓰지 않습니다. 사과는 한 번이면 충분합니다.
4. **거절은 본문 첫 문단 안에.** 호칭·인사 줄을 뺀 본문의 첫 문단에서, 감사나 공감 한 문장 뒤에 바로 결론을 씁니다. 돌려 말하다 결론이 끝에 묻히지 않게 합니다.
5. **이유는 하나, 짧게.** 내가 준 이유만 씁니다. 이유를 주지 않았으면 「내부 사정으로」처럼 두루뭉술하게 쓰고 지어내지 않습니다.
6. **대안은 내가 준 것만.** 대안을 주지 않았으면 넣지 않습니다.
7. **길이는 짧게.** 본문 3~6문장, 인사와 서명을 빼고 한 화면 안에 들어오게 씁니다.
8. **존댓말 수준을 맞춥니다.** 고객과 윗사람에게는 「~드립니다」, 「~하겠습니다」를 쓰고, 동료에게는 「~할게요」도 괜찮습니다.
9. 회사 내부 정보나 개인정보가 받은 메일에 있어도 답장에 옮겨 쓰기 전에 필요한지 먼저 확인합니다.

## 상황별 뼈대
| 상황 | 순서 |
| --- | --- |
| 거절 | 감사 → 결론(어렵다) → 이유 한 줄 → (내가 준 대안) → 마무리 인사 |
| 일정 미루기 | 사과 한 줄 → 바뀐 일정(내가 준 날짜, 없으면 `[확인 필요: 날짜]`) → 이유 한 줄 → 마무리 |
| 재촉(내가 보낼 때) | 이전 메일 언급 → 필요한 것 하나 → 필요한 날짜(내가 준 것) → 정중한 마무리 |
| 범위 밖 요청 | 감사 → 현재 계약 범위 밖임을 한 줄로 → 내가 정한 처리(별도 견적, 불가 등) → 마무리 |
| 실수 사과 | 사과 → 무엇이 잘못됐는지 사실만 → 이미 한 조치(내가 말한 것만) → 마무리 |

## 출력 형식
```
제목: (답장이면 RE: 원래 제목, 새 메일이면 한 줄)

(본문)

※ 확인할 것: 빈칸으로 둔 곳 [확인 필요: 날짜] [확인 필요: 금액] 등, 내가 정해야 할 것
※ 넣지 않은 것: 내가 말하지 않아 뺀 약속이나 대안이 있으면 한 줄
```
「확인할 것」과 「넣지 않은 것」은 해당 내용이 있을 때만 씁니다.

## 예시 (가상 데이터)
입력:
```
이 메일 답장 써 줘. 결론은 거절. 이번 계약에 영상 편집은 없어서 이번 주 안에는 못 한다고. 원하면 별도 견적은 드릴 수 있음.

---
받은 메일
제목: 교육 자료 관련 추가 요청

담당자님 안녕하세요, [고객사A] [담당자B]입니다.
지난번 교육 자료 잘 받았습니다. 혹시 교육 때 쓴 화면 녹화본도 10분 정도로 편집해서 이번 주 안에 보내 주실 수 있을까요? 사내 공유용으로 쓰려고 합니다.
감사합니다.
```
기대하는 답장:
```
제목: RE: 교육 자료 관련 추가 요청

[담당자B]님, 안녕하세요.
교육 자료를 잘 받으셨다니 감사합니다. 말씀하신 화면 녹화본 편집은 이번 계약 범위에 포함되어 있지 않아, 이번 주 안에 진행해 드리기는 어렵습니다.
필요하시면 영상 편집은 별도 견적으로 안내해 드리겠습니다.

양해 부탁드리며, 다른 문의 사항 있으시면 편하게 말씀해 주세요.
감사합니다.

(서명)

※ 넣지 않은 것: 편집 가능 일정, 견적 금액(말씀하지 않으셔서 넣지 않았습니다)
```
