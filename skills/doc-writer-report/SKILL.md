# 메모 → 개조식 보고서

받은 글을 **개조식 보고서**로 바꿉니다. 읽는 사람은 바쁜 윗사람이라고 생각하고, 결론을 맨 위에 둡니다. 개조식은 문장을 길게 잇지 않고 항목으로 끊어 짧은 말로 끝맺는 보고서 방식입니다.

> 이 스킬은 stanlee7의 `korean-office-skills` 중 `report-gaejosik`(MIT 라이선스)을 바탕으로 고쳐 만들었습니다. 라이선스 전문은 같은 폴더의 `LICENSE-stanlee7.txt`에 있습니다.

## 내가 고칠 수 있는 설정
- 보고 대상: 팀장 (예: 임원, 대표, 다른 팀)
- 분량: 한 장 안팎
- 꼭 넣을 항목: (여기에 적어 주세요)
- 쓰지 않을 말: (여기에 적어 주세요)

## 하는 일
1. 입력을 확인합니다. 입력이 비어 있으면 보고서를 쓰지 않고 한 번만 안내합니다. 예: 「보고서로 만들 메모나 글을 붙여 넣어 주세요. 메일이나 회의 정리도 괜찮습니다.」
2. 회사에서 쓰는 보고서 양식(칸 이름, 순서)을 받았으면 그 양식을 따르고, 없으면 아래 기본 형식을 씁니다.
3. 아래 규칙에 맞춰 보고서를 씁니다.
4. 결과를 대화창에 보여 주고 고칠 곳이 있는지 묻습니다. 확정되면 Word나 한글에 붙여 넣으면 됩니다.

## 지키는 것
1. **결론 먼저.** 맨 위 `□ 결론` 아래 한두 줄로 「그래서 무엇을 하자는 것인지」 또는 「무엇이 확인됐는지」를 씁니다. 원문에 결론이 없으면 `○ 원문에 결론 없음 [확인 필요]`라고 쓰고 지어내지 않습니다.
2. **항목 기호는 세 단계만.** 큰 항목 `□`, 그 아래 `○`, 그 아래 `-`. 네 단계 이상 들어가지 않습니다.
3. **끝맺음은 명사형.** 문장은 「~함」, 「~임」, 「~ 예정」, 「~ 필요」, 「~ 완료」로 끝냅니다. 「~합니다」, 「~했어요」 같은 서술형을 쓰지 않습니다. 「A사: 월 9만 원」처럼 이름과 값을 나열하는 줄은 명사로 끝내도 됩니다.
4. **한 줄에 한 가지.** 한 줄이 두 줄을 넘으면 나눕니다. 접속사(그리고, 그래서, 하지만)로 문장을 잇지 않습니다.
5. **숫자는 원문에 있는 것만.** 금액, 건수, 비율, 날짜를 새로 만들거나 합계, 증감률을 계산해 덧붙이지 않습니다. 「넘어」, 「이상」, 「약」 같은 범위 표현도 원문 그대로 옮깁니다(「7년 넘어」를 「7년 이상」으로 바꾸지 않습니다). 원문에 숫자가 없으면 숫자 없이 씁니다. 내가 계산을 요청한 경우에만 계산하고 `(원문 수치로 계산)`이라고 표시합니다.
6. **근거 없는 판단은 표시합니다.** 「효과가 클 것임」, 「문제없음」처럼 원문에 근거가 없는 평가나 전망은 쓰지 않습니다. 꼭 필요하면 그 줄 끝에 `[확인 필요]`를 붙입니다.
7. **원문의 사실을 빼지 않습니다.** 줄이되 결정, 일정, 담당, 위험 요소는 남깁니다. 「가능하면」, 「되도록」 같은 조건·완화 표현은 뜻이 달라지므로 「가능하면 11월 안」처럼 살립니다. 뺀 내용이 있으면 맨 끝에 한 줄로 알립니다.
8. 회사 내부 정보나 개인정보가 원문에 있으면 보고서에 넣기 전에 넣어도 되는지 먼저 확인합니다. 이름, 전화번호, 주소처럼 사람을 특정하는 정보가 대상입니다. 「김대리」처럼 직함과 성만 있는 담당자 표기는 그대로 써도 됩니다.
9. **결론은 원문이 말한 것만.** 원문에 「교체한다」는 말이 없는데 현황만 보고 「교체 필요」라고 결론내리지 않습니다.

## 기본 형식 (양식이 없을 때)
```
# (보고 제목: 원문 주제를 한 줄로)

□ 결론
  ○ ...

□ 현황
  ○ ...
    - ...

□ 문제점 (원문에 있을 때만)
  ○ ...

□ 향후 계획
  ○ ...

□ 요청 사항 (원문에 있을 때만)
  ○ (누구에게, 무엇을)

※ [확인 필요] 표시 항목: (번호나 짧은 설명. 표시한 곳이 없으면 이 줄을 쓰지 않고, 「없음」이라고도 쓰지 않습니다)
```
원문에 없는 큰 항목(문제점, 요청 사항)은 통째로 뺍니다. 「향후 계획」이 원문에 하나도 없으면 `○ 원문에 없음 [확인 필요]`라고 씁니다. 하나라도 있으면 「원문에 없음」 줄을 따로 만들지 않고, 빠진 정보는 맨 끝 `※ [확인 필요] 표시 항목`에만 적습니다.

## 예시 (가상 데이터)
입력:
```
개조식 보고서로 정리해 줘.

이번에 사내 복합기 교체 건 알아봤는데요, 지금 쓰는 복합기가 3대인데 그중 2대가 7년 넘어서 고장이 잦아요. 지난달에만 수리 요청이 5번 들어왔고 수리비로 48만 원 나갔습니다. 업체 두 군데에서 견적 받았는데 A사는 대당 월 임대료 9만 원, B사는 11만 원인데 B사는 토너 무상 포함이에요. 아직 토너 사용량을 정확히 몰라서 어느 쪽이 싼지는 비교를 못 했어요. 총무팀에서 다음 주 수요일까지 토너 사용량 뽑아 주기로 했고, 그거 받으면 최종 비교해서 다시 보고드리겠습니다. 교체는 가능하면 11월 안에 했으면 좋겠습니다.
```
기대하는 결과:
```
# 사내 복합기 교체 검토 보고

□ 결론
  ○ 업체 선정은 토너 사용량 확인 후 최종 비교 예정
  ○ 교체 희망 시기는 가능하면 11월 안임

□ 현황
  ○ 보유 복합기 3대 중 2대가 7년 넘게 사용, 고장 잦음
    - 지난달 수리 요청 5건, 수리비 48만 원 발생함
  ○ 업체 2곳 견적 받음
    - A사: 대당 월 임대료 9만 원
    - B사: 대당 월 임대료 11만 원, 토너 무상 포함

□ 문제점
  ○ 토너 사용량 미파악으로 두 업체 비용 비교 못 함

□ 향후 계획
  ○ 총무팀에서 다음 주 수요일까지 토너 사용량 자료 받기로 함
  ○ 자료 받은 뒤 최종 비교해 재보고 예정
```
