# TASKS — 작업 계획

약 2주(주말·퇴근 후 기준). 설치 검증을 먼저 해야 안내문이 정확해진다.

## 1단계 · 스킬 검증 (1~3일)
- [ ] `blog-writer-naver` 스킬 완성 및 본인 PC에서 동작 확인
- [ ] 깨끗한 환경 기준 설치 경로·재시작 필요 여부·실행법 확인 (맥/윈도우)
- [ ] 글 초안 작성과 자동 게시 각각의 필요 조건 정리
- [ ] 결과물 예시용 블로그 글 생성 + 스크린샷

## 2단계 · 콘텐츠 제작 (3~5일)
- [ ] 설치 단계 스크린샷 (맥/윈도우)
- [ ] 설치 쇼츠 영상 30~60초
- [ ] 안내 문구 작성: 준비물, 안심 안내, 기능 구분 표, FAQ
- [ ] 다운로드용 ZIP 패키징

## 3단계 · 사이트 구현 (4~5일)
- [ ] 프로젝트 세팅 + 디자인 토큰 적용 (`DESIGN.md` 기준)
- [ ] 목록 페이지: `skills.json` → 스킬 카드 그리드, 빈 카드
- [ ] 상세 페이지 `/skills/:id` + 섹션 컴포넌트 (제목 → 안심 → 예시 → 준비물 → 설치 → FAQ)
- [ ] 모바일 확인, 다운로드 동작 확인
- [ ] Cloudflare Pages 배포 (상세 경로 새로고침 시 404 나지 않는지 확인)

## 4단계 · 친구 테스트 (3~5일)
- [ ] 비개발자 3명에게 링크만 전달, 옆에서 보지 않기
- [ ] 막힌 지점·소요 시간 기록
- [ ] 안내문 수정 후 재배포, 다음 스킬 추가 여부 결정
