# TASKS — 작업 계획

목표: **3일 안에 MVP 제작·배포·테스트**. 병목은 사이트 구현이 아니라 설치 경로 확인, 스크린샷, 친구 테스트다.
사이트 틀은 확인 전 값을 `[확인 필요]`로 둔 채 먼저 만들고, 확인된 값을 나중에 채운다.

## 1일차 · 스킬 검증 + 사이트 구현
사용자
- [ ] `blog-writer-naver` 스킬 완성 및 본인 PC에서 동작 확인
- [ ] 직접 설치해 설치 경로·앱 재시작 필요 여부·실행법 확인 (**현재 쓰는 OS 하나만**, 나머지 OS는 `[확인 필요]`로 둠)
- [ ] 글 초안 작성과 자동 게시 각각의 필요 조건 정리
- [ ] 결과물 예시용 블로그 글 생성

개발
- [ ] 프로젝트 세팅(Astro, 순수 CSS) + 디자인 토큰 적용 (`DESIGN.md` 기준)
- [ ] 목록 페이지: `skills.json` → 스킬 카드 그리드, 빈 카드
- [ ] 상세 페이지 `/skills/:id` + 섹션 컴포넌트 (제목 → 안심 → 예시 → 준비물 → 설치 → FAQ)
- [ ] 모바일 확인, 다운로드 동작 확인

## 2일차 · 콘텐츠 + 배포
사용자
- [ ] 설치 단계 스크린샷 (현재 OS 기준)
- [ ] 확인한 설치 경로·재시작 여부 전달

개발
- [ ] 다운로드용 ZIP 패키징
- [ ] 확인된 값 반영, 안내 문구 정리: 준비물, 안심 안내, 기능 구분 표, FAQ
- [ ] Cloudflare Pages 배포 (상세 경로 새로고침 시 404 나지 않는지 확인)

## 3일차 · 친구 테스트
- [ ] 비개발자 2~3명에게 링크만 전달, 옆에서 보지 않기
- [ ] 막힌 지점·소요 시간 기록
- [ ] 안내문 수정 후 재배포, 다음 스킬 추가 여부 결정

## MVP 이후로 미룸
- 설치 쇼츠 영상 (스크린샷 + 텍스트로 대체)
- 나머지 OS(맥/윈도우 중 미검증 쪽) 설치 검증
- 방문·다운로드 클릭 측정(F11)
