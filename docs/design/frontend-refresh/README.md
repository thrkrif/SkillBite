# 프론트 개선 시안과 검증

승인한 [시안](reference.png)을 기준으로 목록과 상세 화면을 개선했습니다. 시안은 생성 이미지이며 실제 브라우저 스크린샷이 아닙니다.

## 반영 내용

- 목록: 큰 소개 제목, 사용 순서 도해, 스킬 카드, 준비 중 카드, 사용 방법 안내.
- 상세: 분류·다운로드·안심 안내, 명시적인 구성 예시, 준비물·추가 연결 구분, 기존 맥 설치 안내.
- 공통: 탐색, 본문 건너뛰기, 키보드 포커스, 반응형, JavaScript 없는 기본 접근.
- 기존 Astro 정적 빌드와 순수 CSS 유지. 의존성 추가 없음.
- 예시는 skills.json 선택 필드로 제공하며 특정 스킬 ID에 따라 화면을 분기하지 않습니다.

## 검증

- `npm run build`: 목록·상세 정적 페이지 생성 통과.
- `npm run lint:branch`, `git diff --check`: 통과.
- 목록과 상세를 각각 1440×1000, 768×1024, 390×844, 320×844에서 확인: 가로 넘침 없음, h1 각 1개, 목록 3/2/1열.
- 카드 이동, 실제 파일 미리보기, OS 전환·복귀, FAQ 키보드 열기·닫기, 폴더 문제 해결 안내: 통과.
- 클립보드 복사 성공과 실패 안내, 실제 ZIP 다운로드와 폴더 구조 확인: 통과.
- JavaScript 비활성 상태에서 설치 안내와 FAQ 접근: 통과.
- 독립 소스 리뷰: 새 기능의 차단 결함 없음. 기존 설치 FAQ와 상수의 중복, OS 선택자의 문서 전체 범위는 후속 정리 항목입니다.

## 시안과 차이·한계

전체 설치 설명은 축약하지 않고 세로 단계로 유지했습니다. 결과물은 실제 실행 자료로 오인하지 않도록 문장으로 된 구성 예시를 사용합니다. 그림자는 디자인 기준에 따라 제거했고 재시작 안내는 확인된 최신 데이터를 사용합니다.

브라우저 화면 캡처 도구의 타임아웃으로 스크린샷 기반 픽셀 차이 검증과 90점 통과 여부는 확인하지 못했습니다. DOM·레이아웃 측정과 브라우저 PDF 렌더링은 보조 검토에만 사용했습니다.

실제 결과물 이미지, 윈도우 설치 경로, 피드백 URL, 최종 로고는 열린 항목입니다.
