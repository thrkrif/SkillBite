**AI가 만든 템플릿처럼 보이는 지점**

아래는 제작 방식에 대한 단정이 아니라, 화면에서 받는 인상입니다.

1. **범용적인 도입 문구** — `src/pages/index.astro`, 모든 화면 상단  
   ‘반복되는 업무, 스킬 하나로 시작하세요’는 다른 AI 서비스에도 그대로 들어갈 수 있습니다. 현재 제공하는 네이버 블로그 스킬의 구체적인 입력과 결과가 드러나지 않아 문구를 채운 랜딩 페이지처럼 보입니다.

2. **내용이 얕은 3단계 안내** — `src/pages/index.astro`, 목록 아래 사용 방법  
   ‘파일 받기 → Claude에 추가 → 명령어 입력’은 형식은 완성됐지만 핵심인 추가 방법을 다시 ‘안내에 따라’로 넘깁니다. 특히 768·모바일에서는 굵은 구분선과 넓은 공간이 반복돼 내용보다 틀이 두드러집니다.

3. **모든 스킬의 동일한 시각적 표현** — `src/components/SkillRow.astro`, `home-many-1440.png` 목록  
   서로 다른 업무 9개에 같은 노란 펜 아이콘과 같은 ‘쉬움·브라우저 필요’ 배지가 반복됩니다. 행 구조의 통일성은 좋지만, 업무 차이를 보여주는 정보가 부족해 복제한 예시 목록처럼 보입니다. 테스트용 문구 자체는 운영 콘텐츠로 간주해 감점하지 않았습니다.

4. **서비스의 실체가 약한 푸터** — `src/layouts/Base.astro`, 홈 하단  
   ‘AI와 함께 더 나은 일을 하는 작은 도구들을 모읍니다’와 상단 메뉴의 반복만으로 구성됩니다. 무엇을 기준으로 스킬을 제공하는지보다 포괄적인 슬로건이 남아 기본 템플릿 푸터처럼 느껴집니다.

**가장 먼저 고칠 것 3가지**

1. **첫 화면에서 제공물과 비용 범위를 명확히 해주세요.**  
   네이버 블로그 스킬이 무엇을 받아 무엇을 만드는지 구체적으로 설명하고, ‘스킬 파일 무료’와 Claude 이용 조건을 가까이 배치해주세요. 이용 조건의 사실 여부는 별도 확인이 필요합니다.

2. **320px에서 스킬 행의 본문 폭을 확보해주세요.**  
   작은 화면에서는 아이콘·화살표의 자리와 안쪽 여백을 줄이거나 배치를 바꾸고, 설명과 명령어가 읽기 좋은 단위로 줄바꿈되게 해주세요. 상세로 이동하는 행동도 ‘사용 방법 보기’처럼 명확하게 표시하는 편이 좋습니다.

3. **범용 안내를 실제 사용 예시로 구체화해주세요.**  
   현재 스킬의 짧은 입력·결과 예시를 보여주고, 3단계 안내에는 각 단계에서 무엇을 해야 하는지 적어주세요. 설치 위치처럼 확인되지 않은 내용은 추측해 채우지 않아야 합니다.

정적 이미지로 **실제 가로 스크롤, 검색·필터 동작, 포커스 이동, 대비의 정량 충족 여부**는 검증하지 못했습니다. 이미지 오른쪽과 아래쪽의 회색 영역도 사이트 넘침이라고 단정하지 않았습니다.
