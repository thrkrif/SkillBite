## AI가 만든 것처럼 보이는 곳

1. **스킬 아이콘 반복** (화면: home-many-1440 전체 목록, 소스: src/components/SkillRow.astro `.icon-surface`). 9개 행이 모두 같은 노란 칸과 같은 연필 그림입니다. 스킬 종류를 구분해 주지 못하고 "같은 모양 반복"이라는 템플릿 느낌을 줍니다. 블로그 글 하나만 있는 홈에서도 연필이 유일한 시각 요소라 장식처럼 보입니다.
2. **번호 + 위쪽 선 3열 단계** (화면: home-1440 하단 "처음이라도, 순서대로 따라오세요", 소스: src/pages/index.astro `.steps`). 1·2·3 숫자, 굵은 소제목, 회색 한 줄 설명의 3열 배치는 생성형 도구가 가장 자주 내놓는 패턴입니다. 내용도 "내려받아요 / 넣어요 / 입력해요"로 구체성이 낮아 채움 문구처럼 읽힙니다.
3. **히어로의 일반적 문구와 구조** (화면: home-1440 상단, 소스: src/pages/index.astro `.intro`). "반복되는 업무, 스킬 하나로 시작하세요."는 어느 서비스에도 붙는 문장이고, 큰 제목 아래 회색 설명 문단, 굵은 한 줄 안내가 이어지는 구조에 시각 요소와 행동 버튼이 없습니다. 실제 결과 화면이나 예시가 없어 "누가 써 본 서비스"의 흔적이 안 보입니다.
4. **전부 흰 바탕에 얇은 선으로만 구성** (화면: 전체, 소스: src/styles/global.css `--border`). 어느 곳에도 개성 있는 선택이 없어 안전한 기본값처럼 보입니다. 노랑 사용이 아이콘 칸과 404 버튼뿐이라 브랜드 개성이 약합니다.
5. **태그 3개 고정 패턴** (화면: home-many-1440, 소스: src/components/SkillRow.astro `.tag`). "글쓰기 / 쉬움 / 브라우저 필요"가 모든 행에 같은 형식으로 붙어 정보라기보다 장식으로 보입니다. (샘플 데이터 영향이 큽니다.)

## 가장 먼저 고칠 것

1. **히어로에 행동과 결과를 보여 주기.** 첫 화면에서 스킬 1개를 바로 받을 수 있는 노란 버튼("블로그 글 스킬 받기")과, 결과 예시(실제 만들어진 글 초안 조각이나 사용 장면)를 넣어 5초 안에 "무엇을 주는지"가 보이게 하십시오. 지금은 히어로가 글자뿐이고 노랑이 거의 안 쓰입니다. (src/pages/index.astro)
2. **스킬 아이콘을 스킬마다 다르게 하거나 아이콘 칸을 없애기.** 같은 연필 반복을 걷어내야 목록이 템플릿처럼 보이지 않습니다. 스킬 데이터에 아이콘이 없으면 칸 자체를 빼는 편이 낫습니다. (src/components/SkillRow.astro)
3. **단계 설명을 구체적이고 쉬운 말로 바꾸기.** "스킬", "Claude에 추가", "명령어"를 처음 보는 사람 기준으로 풀어 쓰고(예: 어디에 끌어다 놓는지, 무엇을 입력하는지 한 줄 예시), 3열 번호 패턴도 화면 캡처 같은 실제 자료로 대체할 방법을 찾으십시오. 확인되지 않은 설치 경로는 `[확인 필요]`로 두시기 바랍니다. (src/pages/index.astro `steps`)
