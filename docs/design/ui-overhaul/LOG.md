### 색 변경 (2026-10-25)
- 사유: 노랑 `#F5C842`가 화면에 비해 너무 진해 어울리지 않는다는 사용자 의견.
- 비교: 회흑(A)·딥 그린(B)·네이비(C)를 같은 화면에 적용해 비교(`screenshots/color-options.png`). 사용자가 C(네이비 `#1F3A5F`)를 선택.
- 적용: `--accent` 계열을 네이비로 교체하고 `--on-accent` 토큰 추가. 스킬 아이콘 칸은 연한 네이비 바탕. 로고 심볼의 노랑은 그대로(UI에는 쓰지 않음). `theme-color`·웹 매니페스트는 흰색.
- 참고: 브랜드 브리프의 '파랑 피하기'는 네이비에 한해 해제했다. 상세 화면의 안심 상자(연한 초록)는 그대로.
- 리뷰: 토큰 교체라서 독립 리뷰는 돌리지 않았다. 다음 상세 개편 라운드에서 함께 평가한다.

## 사용자 직접 수정 반영 (2026-10-26)

사용자가 화면 문구와 데이터를 직접 고쳤고, 그에 맞춰 문서를 갱신했습니다.

- 홈 소개: h1을 `반복되는 업무, 파일 하나로 시작하세요.`로, 소개 문장을 세 줄로 바꿈. 사용 방법 2단계는 `지정된 위치로 옮기기`, 3단계는 `/스킬 이름과 [내용]` 입력으로 바꿈.
- 안심 상자(`SafetyBox`) 문장을 세 줄로 나눔.
- `skills.json`: 태그 `쉬움`(주관적 표현) 삭제, `브라우저 필요`를 `네이버 로그인 필요`로 변경(목록에서 보이는 조건은 사용자가 하는 행동이어야 함). 명령어는 `/blog-writer-naver [내용]`. `capabilities` 문구를 `글 초안 작성 (대화창에 출력)` / `네이버 블로그에 자동 입력·게시`로 명확히 함.
- 문서 갱신: `DESIGN.md`(소개, 분류 예시, 필터 기준 4개), `HANDOFF.md`(스키마 예시), `PRD.md`, `SKILL_SPEC.md`(명령어 표기).
- 내려받는 `SKILL.md`와 ZIP의 `주제` 표현도 `내용`으로 통일함(`skills/blog-writer-naver/SKILL.md`, `npm run zip`).
