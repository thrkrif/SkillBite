### 계획 확정 (2026-10-25)
계획만 확정했다. 이후 조사 3건(`research/home-*.md`)과 방향 선택을 거쳤다. 사용자가 고른 방향: 카탈로그형을 기본으로 하되 상단에 비개발자를 위한 짧은 설명을 두고, 스킬이 적을 때는 검색·분류를 숨기고 늘면 같은 화면에서 확장.

- 비고: 캡처는 헤드리스 Chrome의 최소 창 너비 때문에 좁은 너비에서 잘려 보였다. iframe으로 정확한 너비를 만들어 다시 찍었고 실제 넘침은 아니었다. 이후 좁은 너비는 같은 방식으로 캡처한다.

- Claude 점수: 3, 4, 4, 3, 5, 4, 4, 3

- 두 리뷰가 2점 이상 갈린 항목(임의로 정하지 않고 근거를 병기):

  - 5) 신뢰 — Codex 3: 가짜 수치는 없으나 `Claude 유료 구독 필요`·`게시까지 도와준다`는 사실을 자료만으로 검증하지 못했고 파일·폴더 표기가 섞임. Claude 5: 가짜 평점·수치·후기가 없고 무료·가입 없음·구독 필요를 솔직하게 밝힘.

### 색 변경 (2026-10-25)
- 사유: 노랑 `#F5C842`가 화면에 비해 너무 진해 어울리지 않는다는 사용자 의견.
- 비교: 회흑(A)·딥 그린(B)·네이비(C)를 같은 화면에 적용해 비교(`screenshots/color-options.png`). 사용자가 C(네이비 `#1F3A5F`)를 선택.
- 적용: `--accent` 계열을 네이비로 교체하고 `--on-accent` 토큰 추가. 스킬 아이콘 칸은 연한 네이비 바탕. 로고 심볼의 노랑은 그대로(UI에는 쓰지 않음). `theme-color`·웹 매니페스트는 흰색.
- 참고: 브랜드 브리프의 '파랑 피하기'는 네이비에 한해 해제했다. 상세 화면의 안심 상자(연한 초록)는 그대로.
- 리뷰: 토큰 교체라서 독립 리뷰는 돌리지 않았다. 다음 상세 개편 라운드에서 함께 평가한다.
