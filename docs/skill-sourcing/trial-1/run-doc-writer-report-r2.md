## 입력 1

### 입력 요약
서버 약 40대 중 12대가 5년 넘음, 클라우드 이전 결정, 12월 말까지 완료 계획, 보안 검토는 되도록 11월 중, 담당 이과장.

### 응답
```
# 서버 교체(클라우드 이전) 보고

□ 결론
  ○ 서버를 클라우드로 이전하기로 결정함
  ○ 12월 말까지 완료 예정

□ 현황
  ○ 서버 약 40대 중 12대가 5년 넘게 사용됨
  ○ 비용 비교
    - 클라우드 이전 시: 월 약 300만 원 예상
    - 현재 방식 유지 시: 연 4천만 원 정도

□ 향후 계획
  ○ 클라우드 이전 12월 말까지 완료 예정
  ○ 보안 검토는 되도록 11월 중 완료 예정
  ○ 담당: 이과장

※ [확인 필요] 표시 항목: 없음
```

## 입력 2

□ 향후 계획

### 입력 요약
신입 입사자 김민수(주소 포함)의 노트북 지급 완료, 계정 발급은 내일 예정.

### 응답
원문에 이름(김민수)과 주소(서울시 강남구 테헤란로 1)가 들어 있습니다. 보고서에 이 개인정보를 그대로 넣어도 될까요? 넣지 않는 편이 좋다면 이름은 「신입 입사자」로 바꾸고 주소는 뺀 채로 정리하겠습니다. 어떻게 할지 알려 주세요.
