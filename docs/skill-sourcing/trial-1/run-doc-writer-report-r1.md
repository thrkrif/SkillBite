## 입력 1

# 사내 복합기 교체 검토 보고

□ 결론
  ○ 노후 복합기 2대 교체 필요, 업체 선정은 토너 사용량 확인 후 최종 비교 예정
  ○ 교체 희망 시기는 11월 안임

□ 현황
  ○ 보유 복합기 3대 중 2대가 7년 이상 사용, 고장 잦음
    - 지난달 수리 요청 5건, 수리비 48만 원 발생함
  ○ 업체 2곳 견적 받음
    - A사: 대당 월 임대료 9만 원
    - B사: 대당 월 임대료 11만 원, 토너 무상 포함

□ 문제점
  ○ 토너 사용량 미파악으로 두 업체 비용 비교 못 함

□ 향후 계획
  ○ 총무팀에서 다음 주 수요일까지 토너 사용량 자료 받기로 함
  ○ 자료 받은 뒤 최종 비교해 재보고 예정
