# PLAN — SkillBite MVP

**한 줄 정의**: 비개발자가 "스킬 파일 1개 다운로드 → `/스킬이름` 실행"만으로 Claude의 확장 기능을 처음 경험하게 하는 정적 사이트.

**검증할 가설**: 파일 위치와 실행법만 쉽게 알려주면, 터미널·GitHub을 모르는 Claude 유료 사용자도 스킬을 설치해 실제로 결과물을 얻는다.

| 구분 | 내용 |
| --- | --- |
| 범위 (In) | 스킬 목록(카드 그리드) + 스킬 상세 페이지(설명·다운로드·설치 안내), 첫 스킬 `blog-writer-naver` 1개 / 결과물 예시 / 안심 안내 / 커스텀 안내 / 설치 쇼츠 영상 |
| 비범위 (Out) | 로그인, DB, 백엔드, 사이트 내 AI 실행, 결제, 스킬 업로드/등록, 검색·정렬·리뷰 |
| 사용자 전제 | Claude 유료 요금제 + Claude 데스크톱 앱 또는 터미널 + 브라우저 제어 도구(Claude in Chrome 등, 네이버 자동 게시 시) |

## 성공 기준 (친구 테스트)
- 안내문만 보고 혼자 설치·실행에 성공한 사람 3명 중 2명 이상
- 설치 완료까지 10분 이내
- 막힌 지점이 기록되어 안내문에 반영됨

## 원칙
서버·비용·로그인이 없는 구조를 유지한다. 기능 추가보다 안내의 명확함이 우선이다.

## 배포
Cloudflare Pages 무료 주소(`*.pages.dev`)로 시작. 반응 확인 후 도메인 구매.
