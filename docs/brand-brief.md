# SkillBite 로고 브리프

로고 제작용 요약 지시서다. 이 문서는 방향만 정하고 로고는 만들지 않는다. 모든 항목은 사용자가 직접 골라 확정했다.

## 서비스

**파일 하나로 시작하는 업무 자동화.** SkillBite는 한 입거리처럼 쉽게 쓰는 Claude 스킬 파일(SKILL.md)을 제공한다. 비개발자가 파일 하나를 내려받으면 반복 업무를 자동화할 수 있다. 개발 지식이 없어도 시작할 수 있게 진입 장벽을 낮추는 것이 목적이다.

## 타깃

반복 업무가 많은 일반 직장인. 웹에서 AI를 써봤고 Claude 유료 구독 중이지만, 파일 설치나 숨김 폴더는 낯설다.

## 성격 (키워드 3개)

친절한 · 단정한 · 믿음직한

## 색

| 역할 | 값 | 비고 |
| --- | --- | --- |
| 메인(로고) | 버터 옐로 `#F5C842` | 로고 심볼의 면에만 쓴다. 사이트 UI에는 쓰지 않는다(2026-10-25 변경) |
| 사이트 강조 | 네이비 `#1F3A5F` | 사이트의 주 버튼·선택 표시. 노랑이 화면에 비해 너무 진해 대체함 |
| 보조 | 짙은 회흑 `#242424` | 글자·윤곽·심볼에 쓴다 |
| 피할 색 | 밝은 파랑·보라 계열 | 네이비는 사이트 강조색으로 허용(2026-10-25 변경) |
| 피할 색 | 주황 (Zapier `#ff4a00`, Claude `#d97757` 근삿값) | 경쟁 서비스와 겹침 |

주의: 버터 옐로는 밝아서 흰 배경 위의 글자나 가는 선으로 쓰면 작은 크기에서 흐려진다. 노랑은 면 색으로만 쓰고, 글자와 윤곽은 회흑으로 한다.

## 스타일

심볼 + 워드마크 가로형. 단순한 단색 심볼을 글자 옆에 붙인다. 심볼은 따로 떼어 파비콘과 앱 아이콘으로 쓴다.

## 레퍼런스

Gumroad: 굵은 검정과 밝은 면 색 조합의 친근한 분위기.
참고: 근거는 사이트 UI 설명이고, 로고 자체의 형태는 일부 확인하지 못했다. 색 조합과 굵기 감각만 참고한다.

## 금지 사항

- 스파클, 별, 번개, 로봇, 두뇌, 신경망 노드
- 그라데이션, 네온, 유리 효과, 그림자
- 파랑·보라 계열, 주황(Claude·Zapier 색)

선택하지 않아 금지에 넣지 않은 것: 베어 문 음식·쿠키·사과 모양, 캐릭터·마스코트. 다만 앞선 시안에서 한 입 모양이 마음에 들지 않았다는 반응이 있었으므로, 쓰더라도 중심 아이디어로 삼지 않는다.

## 요구 조건

- 16px 파비콘에서도 식별되어야 한다. 심볼만 따로 떼어 쓴다.
- 흑백(회흑 단색, 흰색 반전)에서도 성립해야 한다.
- 시안 6개는 서로 방향이 확실히 달라야 한다. 색만 바꾼 변형이나 크기·간격만 조정한 변형은 안 된다.

## 조사 요약 (근거)

조사 7곳: Zapier, Make, IFTTT, Claude, Raycast, Notion, Gumroad. PromptBase와 뤼튼은 정보를 찾지 못했다. 대부분 제3자 자료라 hex는 근삿값이고, 공식 브랜드 가이드를 직접 확인한 곳은 거의 없다.

- 스타일: 단색 워드마크, 또는 작은 심볼 + 워드마크 조합이 다수.
- 색: 흑백 단색이 가장 많고, 그다음이 주황·적주황 계열. 파랑을 주색으로 쓴 곳은 드물었다.
- 클리셰: 스파클·번개·노드·보라-파랑 그라데이션은 조사한 곳에서 확인하지 못했다. 일반 통념일 뿐 이번 조사의 근거는 없다.
