# PRD — SkillBite MVP

## 타깃 사용자
웹 브라우저에서만 AI를 써본 비개발자. Claude 유료 구독 중이고, "내 컴퓨터에 무슨 일이 생길까" 걱정해 설치를 망설인다.

## 핵심 사용자 흐름
목록 접속 → (필요하면 분류 선택) 스킬 행 클릭 → 상세에서 결과물 예시 확인 → 준비물 체크 → 파일 다운로드 → 설치 위치에 넣기 → `/blog-writer-naver [내용]` 실행 → (선택) 파일 열어 수정

## 화면
| 화면 | 경로 | 역할 |
| --- | --- | --- |
| 목록 | `/` | 짧은 소개 아래 스킬 목록에서 고른다. 사용 방법 3단계 |
| 404 | (없는 경로) | 목록으로 돌아가게 한다 |
| 상세 | `/skills/:id` | 설명 → 준비물 → 설치 → 다운로드 |

## 기능 요구사항
| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| L1 | 목록: 한 줄 행 목록(아이콘·제목·설명·태그·명령어), 행 전체 클릭 시 상세로 이동. 좁은 화면에서는 세로로 쌓임 | Must |
| L2 | 스킬 행: 아이콘·제목·한 줄 설명·분류와 태그(필요 조건 등, 주관적 표현인 난이도는 쓰지 않음)·명령어 | Must |
| L3 | 스킬이 적을 때 "새 스킬은 준비되는 대로 추가돼요" 한 줄 (빈 카드는 쓰지 않음) | Should |
| L4 | 분류 필터(스킬 4개 이상·분류 2개 이상일 때), 검색(8개 이상일 때). 자바스크립트가 없어도 목록은 보임 | Should |
| L5 | 분류는 작업 종류 한 축만 사용(글쓰기, 문서 작성). 도구는 나중에 별도 필드 | Should |
| F1 | 상세 상단: 제목·한 줄 설명. 다운로드 버튼과 명령어·필요한 것은 요약 사이드바(좁은 화면에서는 제목 아래) | Must |
| F2 | 결과물 예시: 실제 생성된 블로그 글 스크린샷 | Must |
| F3 | 준비물 체크리스트: Claude 유료 요금제, 데스크톱 앱/터미널, Claude in Chrome 등 브라우저 제어 도구 | Must |
| F4 | 다운로드: ZIP(폴더 구조 유지) 직접 다운로드, 로그인 불필요 | Must |
| F5 | 설치 안내: OS별(맥/윈도우) 경로, 숨김 폴더 여는 법, 스크린샷 + 쇼츠 영상 | Must |
| F6 | 실행 안내: `/blog-writer-naver [내용]` 입력 예시 | Must |
| F7 | 안심 안내(박스 없이 한 줄 사실): "스킬은 텍스트 지침 파일이며 실행 파일이 아닙니다" + 파일 내용 미리보기 | Must |
| F8 | 기능 구분 표: 글 초안 작성(조건 없음) / 자동 입력·게시(브라우저 연결 + 로그인). 문서 스킬은 초안 작성 / 파일 저장 | Must |
| F9 | 커스텀 안내: 메모장으로 열어 문장 수정하는 법 | Should |
| F10 | 자주 막히는 점(FAQ) + 피드백 링크 | Should |
| F11 | 방문·다운로드 클릭 측정(익명 통계) | Could |

## 비기능 요구사항
모바일에서도 읽기 쉬움, 첫 화면 로딩 2초 이내, 한국어 우선, 계정·쿠키 동의 불필요.

## 수용 기준(핵심)
비개발자 테스터가 사이트만 보고 파일 위치를 찾아 스킬 하나(예: `/blog-writer-naver`)를 실행해 초안을 받는다.

## 열린 질문

- [ ] 스킬 파일을 공개 저장소에 둘지, 사이트에서만 배포할지
