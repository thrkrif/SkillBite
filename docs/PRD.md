# PRD — SkillBite MVP

## 타깃 사용자
웹 브라우저에서만 AI를 써본 비개발자. Claude 유료 구독 중이고, "내 컴퓨터에 무슨 일이 생길까" 걱정해 설치를 망설인다.

## 핵심 사용자 흐름
목록 접속 → 스킬 카드 클릭 → 상세에서 결과물 예시 확인 → 준비물 체크 → 파일 다운로드 → 설치 위치에 넣기 → `/blog-writer-naver 주제` 실행 → (선택) 파일 열어 수정

## 화면
| 화면 | 경로 | 역할 |
| --- | --- | --- |
| 목록 | `/` | 스킬 카드 그리드에서 고른다 |
| 상세 | `/skills/:id` | 설명 → 준비물 → 설치 → 다운로드 |

## 기능 요구사항
| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| L1 | 목록: 스킬 카드 그리드(데스크톱 3열 / 태블릿 2열 / 모바일 1열), 카드 전체 클릭 시 상세로 이동 | Must |
| L2 | 스킬 카드: 아이콘·제목·설명 2줄·태그(난이도, 필요 조건) | Must |
| L3 | "다음 스킬 준비 중" 빈 카드 (스킬 1개일 때도 마켓 구조 전달) | Should |
| L4 | 카테고리 칩 필터 (스킬 3개 이상일 때) | Could |
| F1 | 상세 상단: 제목·한 줄 설명 + 다운로드 버튼 | Must |
| F2 | 결과물 예시: 실제 생성된 블로그 글 스크린샷 | Must |
| F3 | 준비물 체크리스트: Claude 유료 요금제, 데스크톱 앱/터미널, Claude in Chrome 등 브라우저 제어 도구 | Must |
| F4 | 다운로드: ZIP(폴더 구조 유지) 직접 다운로드, 로그인 불필요 | Must |
| F5 | 설치 안내: OS별(맥/윈도우) 경로, 숨김 폴더 여는 법, 스크린샷 + 쇼츠 영상 | Must |
| F6 | 실행 안내: `/blog-writer-naver [주제]` 입력 예시 | Must |
| F7 | 안심 안내: "스킬은 텍스트 지침 파일이며 실행 파일이 아닙니다" + 파일 내용 미리보기 | Must |
| F8 | 기능 구분 표: 글 초안 작성 / 브라우저 연결 필요 / 자동 게시 | Must |
| F9 | 커스텀 안내: 메모장으로 열어 문장 수정하는 법 | Should |
| F10 | 자주 막히는 점(FAQ) + 피드백 링크 | Should |
| F11 | 방문·다운로드 클릭 측정(익명 통계) | Could |

## 비기능 요구사항
모바일에서도 읽기 쉬움, 첫 화면 로딩 2초 이내, 한국어 우선, 계정·쿠키 동의 불필요.

## 수용 기준(핵심)
비개발자 테스터가 사이트만 보고 파일 위치를 찾아 `/blog-writer-naver`를 실행해 글 초안을 받는다.
